# AI Resume Evaluator & Career Coach

An intelligent, ATS-style resume evaluation tool powered by Google's Gemini LLM. It matches a candidate's resume (PDF) against a Job Description, provides a match percentage, and features an interactive AI Career Coach chatbot.

## Features
-  **ATS Match Analyzer:** Calculates match percentage and identifies missing skills.
-  **AI Career Coach:** Chat with the AI for interview tips and cover letter generation.
-  **Modern UI:** Built with Streamlit featuring a clean, responsive light theme.

## Tech Stack
- Python, Streamlit, PyPDF2, Google GenAI SDK (Gemini)
