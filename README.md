# AI Resume Evaluator and Career Coach

An intelligent, ATS-style evaluation tool powered by generative AI. This application allows users to match their PDF resumes against specific job descriptions and features an interactive AI career coach to help optimize their professional profile.

## Core Features
* Features a Resume Match Analyzer where users can input job requirements and upload a PDF format resume.
* Includes a dedicated Evaluate Match function to analyze the uploaded documents.
* Provides an interactive AI Career Coach interface to offer personalized advice and resume optimization.
* Offers pre-configured quick question prompts for users, including options to ask how to improve scores, recommend projects, or draft cover letters.
* Delivers structured, actionable feedback, such as specific strategies to upgrade project descriptions or highlight relevant technical architectures.
